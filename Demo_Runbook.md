# Demo Runbook — AI STUDY BUDDY API

1. Open `Code Files`.
2. Run `npm install`.
3. Configure `.env` with MongoDB, JWT secrets and Gemini API key.
4. Start the Node.js API.
5. Verify the root endpoint.
6. Register/login a student.
7. Upload study material.
8. Demonstrate:
   - `/api/materials/:id/summarize`
   - `/api/materials/:id/flashcards`
   - `/api/materials/:id/quiz`
   - `/api/materials/:id/study-plan`
9. Demonstrate admin statistics and user management.
10. Explain the architecture, security controls, limitations and future enhancements.

## Suggested Presentation Order

Problem → Solution → Architecture → Authentication → Material Upload → AI Summary → Flashcards → Quiz → Study Plan → Admin APIs → Security → Future Scope → Conclusion.
