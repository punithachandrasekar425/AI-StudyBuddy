## Project Summary

AI Study Buddy API is an AI-powered educational backend built with Node.js, Express, MongoDB/Mongoose and Google Gemini 2.5 Flash. It supports authentication, study-material upload, AI summarization, flashcard generation, quiz generation, personalized study plans and admin management.
